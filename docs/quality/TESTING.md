# 테스트 품질

상태: 활성

테스트 모음은 다음을 포함합니다.

- Spring Boot·MockMvc 애플리케이션 동작
- 집중 Service·Facade·Controller 단위 테스트
- Entity 상태 전이 테스트
- 락·복구·멱등성 테스트
- mock S3 어댑터 테스트
- Flyway 적용과 JPA 검증

초기 기준선은 테스트 63개와 알려진 통합 실패 9개였으며, 결제 클라이언트
설정·인증 계약 테스트를 추가한 현재 발견 집합은 68개입니다. 검증된 coverage
기준선이 없으므로 하네스는 임의의 coverage 임계값을 설정하지 않습니다.
현재 품질은 정확한 실패 식별자, 아키텍처 검사, 마이그레이션 무결성, 이름이
있는 위험 평가로 래칫됩니다.

향후 coverage 작업은 다음 원칙을 따릅니다.

1. 유지보수되는 Gradle 도구로 현재 line·branch 기준선을 측정합니다.
2. 생성 코드와 framework 전용 코드를 명시적으로 제외합니다.
3. 목표를 높이기 전에 회귀를 방지합니다.
4. 단일 비율 최적화보다 인증, 결제 오류 매핑, 복구, 보안 경계를 우선합니다.

명령과 상태 의미는 [테스트 runbook](../runbooks/testing.md)을 참고합니다.
