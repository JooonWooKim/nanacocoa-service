## 사용자 흐름

담당자가 로컬에서 실제 모델 파일럿을 명시적으로 실행한다. CLI가 현재 커밋을 기준으로 저장소에 고정한 합성 장애를 생성하고, 모델은 각 사례에서 허용된 원인 후보와 근거를 선택하거나 증거 부족으로 보류한다. 담당자는 검증된 근거와 다음 확인 절차를 읽고 결과의 적절성을 확인한다.

파일럿은 합성 사례 3건을 승인된 전용 프로젝트에서 확인하는 범위다. 기존 CLI의 모의 모드와 입출력 계약을 유지한다. 실제 Slack 연결, 운영 로그 사용, 패치 생성·적용, 분석 결과에 따른 테스트 자동 실행과 운영 배포는 후속이다.

## 실행·데이터 계약

- 하네스의 기존 `incident-analyze`에 `--live-pilot` 단독 실행을 추가한다. 끝까지 통과한 경우 재고 예약 실패, 승인 미확정, 자동 복구 실패 순서로 처리한다. 프로세스 환경에서 전용 프로젝트의 `INCIDENT_ANALYSIS_OPENAI_API_KEY`를 읽고, 요청 대상은 `https://api.openai.com/v1/responses`로 고정한다. API 실패 뒤 모의 결과를 대신 반환하지 않는다. [모델 문서](https://developers.openai.com/api/docs/models/gpt-5.6-luna)
- 사례별 분석 입력은 검증한 합성 이벤트를 분류, 상태, 근거 번호와 허용 후보 ID로 변환한다. 실제 요청·실행 번호와 저장소 경로 및 후보 커밋은 로컬에서 근거 대조에 사용한다. 전송 객체와 근거 허용 목록은 현재 사례에서 새로 구성한다.
- `store: false`, 출력 최대 256토큰, 도구 없는 구조화 응답을 사용한다. 응답은 후보 ID와 근거 번호 또는 증거 부족 판정으로 제한한다. 후보·근거 조합을 로컬 허용 목록에 대조하고, 로컬 문구로 원인 후보와 다음 확인 절차를 결과에 표시한다. [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
- 시간 한도는 사례 시작부터 근거 대조까지 포함한다. 키 누락, 인증·요청 제한·일시 장애, 모델 거절, 증거 부족은 고정 사유의 BLOCKED이고 형식·참조 위반은 FAIL이다. 먼저 발생한 실패나 보류에서 중단한다. 전체 PASS는 세 사례가 유효할 때만 기록한다. 종료 코드는 PASS 0, FAIL 1, BLOCKED 2를 유지한다.
- 결과에 검토할 후보, 근거·출처와 다음 확인 절차, 시도 횟수·소요 시간 및 응답에서 확인한 입·출력 토큰을 기록한다. 사용량을 알 수 없으면 미확인으로 표시한다. API 키와 공급자 응답 원문은 로그와 인수 자료에서 제외한다.

## 인수 검증

| 시나리오 | 확인할 결과 |
| --- | --- |
| 합성 재고 예약 실패 | 선택한 근거에 따라 판매 가능 수량 또는 예약 경합을 확인하고 잠금·전체 롤백 검사를 안내한다. |
| 합성 승인 미확정 | 결과를 미확정으로 표시하고 저장된 거래 상태 조회를 우선 안내한다. |
| 합성 자동 복구 실패 | 같은 실행의 실패 작업을 인용하고 해당 작업의 저장 상태·복구 절차를 확인한다. |
| 모의 HTTP와 회귀 | 기본 모의 모드에서 네트워크 호출이 없음을 확인한다. 키 누락·입력 옵션 혼용·경계 위반·타임아웃·요청 제한·거절·잘못된 출력과 조기 중단을 검증하고 기존 CLI·모의 Slack 및 전체 하네스를 실행한다. |
| 실제 파일럿 인수 | 승인된 전용 프로젝트에서 세 합성 사례를 1회씩 호출한다. 담당자가 근거와 확인 절차를 대조하고, 판정과 토큰 사용량 및 소요 시간을 비식별 기록으로 남긴다. |

## 로컬 구현과 증거

고정 합성 사례와 실제 모델 어댑터를 연결했다. 모의 HTTP 집중 검사 11개에서
세 사례의 호출 순서·입력 제한, 잘못된 후보와 근거, 중단과 무호출 기본 모드를
확인했다. 전체 Python 55개와 H2 Java 268개가 통과했고 전체 하네스는 기존
아키텍처·보안 예외를 유지한 `BASELINED`다. 실제 모델 파일럿은 이 실행 환경에서 전용 프로젝트 키가 없어
`PILOT_KEY_UNAVAILABLE`, 호출 0회로 BLOCKED였다.
