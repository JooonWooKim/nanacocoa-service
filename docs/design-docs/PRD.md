# 서비스 마이페이지 PRD

## 식별자 결정

- 이메일을 로그인 아이디이자 사용자 식별값으로 사용합니다.
- 이메일은 마이페이지에서 조회만 가능하며 수정할 수 없습니다.
- 별도의 로그인 아이디나 내부 회원번호는 노출하지 않습니다.

## 관리할 컬럼

### 1. 아이디(이메일)

- 마이페이지 조회 시 표시
- 수정 불가, 필수, 중복 불가
- 회원가입 시 이메일 형식 검증

### 2. 비밀번호

- 평문 저장 및 응답 금지
- 회원가입과 변경 시 8~72자 검증
- 변경 시 현재 비밀번호, 신규 비밀번호, 확인값 검증

### 3. 이름

- 마이페이지 조회 및 수정
- 필수값, 공백 입력 금지

### 4. 주소

- 마이페이지 조회 및 수정
- 필수값, 공백 입력 금지

### 5. 전화번호

- 마이페이지 조회 및 수정
- 필수값, `010-0000-0000` 형식

### 6. 이메일 수신여부

- 마이페이지 조회 및 수정
- 필수값
- `Y`: 수신, `N`: 수신 거부

## 기능 요구 사항

### P0 - 핵심 기능

- 마이페이지 메뉴는 본인 확인 페이지로 이동하며 현재 비밀번호로 확인 후 진입
- 확인 전 직접 페이지 요청은 확인 페이지로 이동하고 회원정보 API는 `AUTH_03`으로 차단
- 확인은 동일 세션·회원·현재 credential에 결합하여 10분간 유효하며 재로그인·로그아웃·비밀번호 변경으로 무효화
- 5분 시도 구간에서 확인 비밀번호가 5회 틀리면 해당 구간이 끝날 때까지 `AUTH_04`로 재시도 차단
- 새 확인 API는 JSON과 `X-Mypage-Verification: 1` 헤더를 요구하며 교차 출처 preflight를 거부
- 비밀번호를 URL·브라우저 저장소에 보관하지 않고 뒤로 가기 복원 시 서버 확인을 다시 수행

- 인증된 회원의 아이디(이메일), 이름, 주소, 전화번호, 이메일 수신여부 조회
- 유효한 본인 확인 세션에서 이름, 주소, 전화번호, 이메일 수신여부 수정
- 회원정보 수정 폼·요청에는 현재 비밀번호가 없으며 확인 만료 시 다시 본인 확인
- 이메일 변경 차단
- 현재 비밀번호 확인 후 신규 비밀번호와 확인값이 일치할 때 비밀번호 변경
- 모든 필수값과 입력 형식을 서버에서 검증하고 실패 시 저장 차단
- 조회·수정·비밀번호 응답에서 비밀번호 제외

### P1 - 추가 기능

- 프로필 수정은 앞서 완료한 본인 확인을 사용하고, 비밀번호 변경 시에는 현재 비밀번호로 재인증
- 회원가입과 비밀번호 변경에 동일한 8~72자 정책 적용
- 회원가입 시 이름, 주소, 전화번호, 이메일 수신여부를 필수 수집
- 사용자 정보 및 비밀번호 변경 완료 안내

## 범위 제외

- 이메일 변경, 별도 로그인 아이디, 계정 탈퇴, 주문 내역
- 이메일 발송, 주소 검색, 비밀번호 이력과 다른 세션 강제 종료
