# 서비스 마이페이지 PRD

## 관리할 컬럼(필수로 관리되는 컬럼)

### 1. 아이디
- 사용자 식별값
- 마이페이지 조회 시 표시
- 수정 불가
- 필수값
- 중복 불가

### 2. 비밀번호
- 사용자 인증 정보
- 마스킹 처리
- 평문 저장 금지
- 변경 시 신규 비밀번호 입력
- 변경할 비밀번호 확인값과 일치 여부 검증
- 필수값

### 3. 이름
- 사용자 이름
- 마이페이지 조회 및 수정
- 필수값
- 공백 입력 검증

### 4. 주소
- 사용자 주소
- 마이페이지 조회 및 수정
- 필수값

### 5. 전화번호
- 사용자 연락처
- 마이페이지 조회 및 수정
- 필수값
- 전화번호 형식 검증

### 6. 이메일
- 사용자 이메일
- 마이페이지 조회 및 수정
- 필수값
- 이메일 형식 검증

### 7. 이메일 수신여부
- 이메일 수신 동의 여부
- 마이페이지 조회 및 수정
- 필수값
- 관리값
  - Y: 수신
  - N: 수신거부

---

## 변경할 비밀번호 확인 기능

- 신규 비밀번호 입력 필드 제공
- 신규 비밀번호 확인 입력 필드 제공
- 신규 비밀번호와 비밀번호 확인값 일치 여부 검증
- 불일치 시 비밀번호 변경 불가
- 불일치 시 오류 메시지 표시
- 일치 시 비밀번호 변경 가능
- 비밀번호 변경 완료 후 변경 결과 안내

## 기능 요구 사항

### P0 - 핵심 기능

- 마이페이지 사용자 정보 조회
  - 아이디
  - 이름
  - 주소
  - 전화번호
  - 이메일
  - 이메일 수신여부

- 사용자 정보 수정
  - 이름
  - 주소
  - 전화번호
  - 이메일
  - 이메일 수신여부

- 아이디 수정 제한

- 비밀번호 변경
  - 신규 비밀번호 입력
  - 신규 비밀번호 확인 입력
  - 두 입력값 일치 여부 검증
  - 일치 시 비밀번호 변경
  - 불일치 시 변경 차단

- 필수값 검증
  - 이름
  - 주소
  - 전화번호
  - 이메일
  - 이메일 수신여부

- 입력 형식 검증
  - 전화번호 형식
  - 이메일 형식

- 정보 수정 처리
  - 검증 성공 시 저장
  - 검증 실패 시 저장 차단
  - 저장 성공/실패 결과 안내

---

### P1 - 추가 기능

- 정보 변경 전 사용자 인증
  - 비밀번호 확인

- 비밀번호 보안 검증
  - 비밀번호 정책 충족 여부 확인

- 이메일 변경 시 이메일 형식 재검증

- 전화번호 변경 시 전화번호 형식 재검증

- 사용자 정보 변경 완료 안내

- 비밀번호 변경 완료 안내
