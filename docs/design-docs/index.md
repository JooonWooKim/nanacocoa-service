# 설계 문서 인덱스

상태: 활성
갱신 조건: 여러 영역에 영향을 주는 아키텍처 결정을 도입하거나 교체할 때

- [핵심 엔지니어링 원칙](core-beliefs.md)은 안정적인 의사결정 기준을
  정의합니다.
- [최상위 아키텍처](../../ARCHITECTURE.md)는 현재 시스템과 의존성 지도를
  기록합니다.
- 복잡한 변경 제안은 대안과 결정을 포함해
  [활성 실행 계획](../exec-plans/active)에 기록합니다.

아키텍처, runbook, 실행 계획만으로 이해할 수 없는 결정에 한해 전용 설계
문서를 만듭니다. 대체된 문서는 폐기로 표시하고 후속 문서를 연결합니다.
