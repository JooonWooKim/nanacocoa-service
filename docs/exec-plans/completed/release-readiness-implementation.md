## 위험과 롤백

공용 설정은 기존 환경 파일을 덮어쓰지 않는다. 리허설에는 별도 합성 데이터와 Compose 프로젝트 이름을 사용했다. 되돌릴 때는 이번에 추가한 템플릿·초기화·workflow와 관련 문서 변경만 대상으로 삼고 기존 설정과 데이터는 보존한다.
