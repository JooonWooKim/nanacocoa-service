# 공개 GitHub 비실행 스냅샷 게시

상태: 완료

## 목표

현재 master 기준선의 코드와 정적 미디어를 공개용 단일 루트 커밋으로 만들고,
비공개 런타임·테스트·Docker 설정과 로컬 전용 파일이 Git 이력에 포함되지
않도록 검증한 뒤 원격 main 브랜치로 게시합니다.

## 하지 않는 일

- 기존 master 및 codex 브랜치를 변경하거나 원격에 게시하지 않습니다.
- 애플리케이션을 실행 가능한 공개 배포본으로 만들지 않습니다.
- LICENSE를 추가하거나 실제 운영 설정을 공개하지 않습니다.

## 현재 증거

- 원격 저장소는 커밋과 기본 브랜치가 없는 상태입니다.
- 원본 `./scripts/harness check`는 새 회귀 없이 BASELINED로 완료되었습니다.
- 원본 master에는 커밋 1개가 있고 루트 `IMG_2399.HEIC`만 미추적 상태입니다.

## 결정

- 공개 브랜치는 기존 이력의 자식이 아닌 orphan 커밋으로 생성합니다.
- 설정 파일은 `.gitignore`에 등록하고 공개 tree와 이력에서 제외합니다.
- 공개 스냅샷이 자체 실행·테스트·배포 불가능함을 README에 명시합니다.

## 위험과 롤백

공개 브랜치에는 실행 설정이 없어 clone만으로 실행할 수 없습니다. 게시 전에는
공개용 브랜치 삭제만으로 롤백할 수 있고, 게시 후에는 원격 main을 삭제하거나
새 깨끗한 이력으로 교체해야 합니다. 기존 로컬 master와 worktree는 유지합니다.
