# 이슈 #10 주문 목록·상세 조회

상태: 완료

## 목표

회원이 마이페이지에서 본인 주문 목록과 상세, 최신 결제 결과를 조회한다.

## 하지 않는 일

배송 운영과 취소·반품 신청은 SHIP·RETURN에서 제공한다.

## 현재 증거

기존 주문과 품목에 구매 당시 값이 저장되고 승인, 고객 취소, 보상은 기존 결제 흐름에 기록된다.
[주문 목록·상세 PRD](../../product-specs/order-history-prd.md)가 화면과 API의 인수 기준이다.

## 결정

페이지당 20건을 읽고 대표 품목은 페이지에 속한 주문에 대해 일괄 조회한다.
결제 취소 완료는 성공한 고객 취소 기록으로 판정한다. 보상 후 미결제로 돌아온 주문은 결제 실패로 표시한다.
로그인 복귀는 검증한 주문 번호와 페이지로 동일 사이트 경로를 생성한다.

## 위험과 롤백

주문 소유 조건을 모든 조회에 적용한다. 고객 응답 캐시를 막고 화면 이탈 시 주문 데이터를 지운다.
기능 코드를 되돌리면 기존 흐름으로 복귀할 수 있으며 스키마 이행이나 데이터 정리는 필요 없다.

## 미해결 항목

SHIP·RETURN 기능이 제공하는 상태 및 신청 권한 연동은 후속 작업이다. 엄격 테스트의 기존 실패는 NC-TEST-001로 추적한다.
