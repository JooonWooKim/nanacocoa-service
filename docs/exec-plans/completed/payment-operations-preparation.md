# 미확정 결제·환불 운영 PRD와 기능 준비

상태: 완료

## 목표

구현 PRD, GitHub 이슈 #22, 최신 원격 main 기반 feature/22 추적 브랜치를 준비한다.

## 하지 않는 일

애플리케이션 코드·화면·스키마 구현, 기능 검증, 커밋·구현 push·PR 생성·배포는 수행하지 않는다.

## 현재 증거

원격 main `9f264a4`에 PR #17·#21이 병합됐다. PAY 후속은 미확정 거래 운영 경로다.
기존 복구·재시도 컬럼과 주문 락을 재사용할 수 있다. 시작 브랜치는 feature/20이며
기존 변경 문서 4건의 SHA-256을 전환 전후 비교했다.

## 결정

사용자는 조회와 개별 복구를 선택했다. POLICY·RETURN은 정책 확정이 선행되므로
이번에는 PAY 운영 기능의 PRD를 준비한다. 이슈 #22와 origin/feature/22를 생성했고
로컬 feature/22로 전환했다. 기존 사용자 파일은 수정하지 않는다.

## 진행 상황

- 2026-11-18: 이슈 #22와 feature/22를 생성했다. PRD에 화면·API·권한·복구·데이터 영향·인수 기준을 작성했다. 기존 문서 4건의 내용 보존을 확인했다.
- 2026-11-18: 문서 검사를 통과했다. 첫 check는 문서 편집과 겹쳐 fingerprint 변경으로 FAIL이었다. 편집 종료 후 재실행한 check는 139개 테스트 중 기존 health 실패 1건만 재현해 BASELINED로 종료했다. 코드·스키마 변경과 PG 호출은 없다. 완료 증거 기록 후 문서·변경 형식 검사를 다시 수행한다.

## 명령과 증거

| 명령 | 상태 | 증거 |
| --- | --- | --- |
| `git status --short --branch` | PASS | feature/22가 origin/feature/22를 추적하며 기존 변경 보존 |
| `SHA-256 비교` | PASS | 기존 변경 문서 4건의 전환 전후 내용 동일 |
| `./scripts/harness check` 최초 | FAIL | 문서 편집 중 실행해 입력 fingerprint가 변경됨. 재실행으로 해소 |
| `./scripts/harness check` 재실행 | BASELINED | 테스트 139개, skip 0개, 기존 healthApiReturnsOk 실패 1개. architecture·security·migrations·docs·smoke 유지 |

| `./scripts/harness docs` | PASS | 필수 문서·링크·계획·생성 문서 검사 통과 |
| `git diff --check` | PASS | 변경 형식 오류 없음 |

## 위험과 롤백

문서만 변경하며 PG·S3를 호출하지 않는다. 생성한 문서와 이번 인덱스·출시 PRD
변경만 되돌릴 수 있다. 기존 사용자 변경은 삭제·복원하지 않는다. 이슈·원격
브랜치 삭제는 별도 요청 없이 수행하지 않는다.

## 미해결 항목

준비 단계의 미해결 제품 결정은 없다. 실제 구현과 검증은 별도 요청에서 진행한다.
운영 담당자·문의 이관 기준은 기능 출시 전 운영자가 확정한다.

## 완료 조건

PRD·이슈·브랜치가 연결되고 문서 검증과 git diff 검사가 통과해야 한다.
하네스 실행 결과를 분류하고 기존 사용자 변경 보존을 확인한 뒤 completed로 이동한다.
